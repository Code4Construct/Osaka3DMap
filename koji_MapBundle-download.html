安全性と透明性

QGISのZIPプラグインとしてインストールできます。

Release v1.0.0

koji MapBundleは、選択したレイヤ、スタイル、SVGシンボル、印刷レイアウトをZIP形式の地図バンドルとして書き出し・読み込みするQGISプラグインです。

配布ファイルはGitHub Releasesの `koji_MapBundle.zip` です。ZIPは展開せず、QGISのプラグイン管理画面から「ZIPからインストール」を選んで指定してください。

このページでは、Releaseページ、SHA256、VirusTotal確認リンク、GitHub Actionsで作成されたReleaseアセットへのリンクをまとめています。これらは安全性を完全に保証するものではありませんが、配布ファイルの確認材料として利用できます。

配布ファイルの検証情報

GitHub Release v1.0.0 のアセット情報では、配布ZIPのSHA256とVirusTotal確認リンクが公開されています。VirusTotalは malicious=0 / suspicious=0 です。

koji MapBundle v1.0.0
ZIP: koji_MapBundle.zip
Size: 244,901 bytes
Published: 2026-07-05 03:01:05 UTC
SHA256: c087bb918a566ae04860c2a3bf10c24b2b4b72c0ad6ffd12e0d9ff11e15118c7
VirusTotal: malicious=0 suspicious=0

SHA256が一致するかを確認すると、ダウンロードしたZIPがReleaseに掲載されたファイルと同一かどうかを確認できます。

インストール手順

QGISプラグインとして使う場合は、通常のZIPプラグインと同じ手順でインストールします。

ZIPをダウンロードGitHub Release v1.0.0 から `koji_MapBundle.zip` をダウンロードします。ZIPは展開しません。
QGISのプラグイン管理を開くQGISで「プラグイン」メニューから「プラグインの管理とインストール」を開きます。
ZIPからインストール「ZIPからインストール」を選び、ダウンロードした `koji_MapBundle.zip` を指定します。

確認できること

  • GitHub Releasesで配布ファイルを確認できます
  • SHA256でファイルの同一性を確認できます
  • GitHub Actionsでビルド履歴を確認できます
  • GitHubでソースコードを確認できます
  • VirusTotalで検査時点の検知状況を確認できます
