koji GeoTools

Included tools

日常的な GIS 作業を、押しやすい 3 つの処理に整理。

プラグイン本体はツールバーとプラグインメニューに追加されるランチャーです。起動後は必要な処理を選び、各ツールのダイアログからプロジェクトごとの設定を保存しながら使えます。

レイヤセット作成

CSV データから施設配置検討用のレイヤセットを作成します。座標フィールド、CRS、出力先 GeoPackage、プロジェクトへの追加有無を設定できます。

区境界＋2km バッファ

選択した地物から区境界と 2km バッファを作成し、結果をレイヤとして保存します。区域検討の下ごしらえを QGIS 内で素早く進められます。

ポリゴン内地物抽出

選択ポリゴン内にある表示中のポイント地物・ポリゴン地物を抽出して統合します。スタイル継承や source FID 付与にも対応します。

Project based settings

設定はプロジェクトごとに分離。

koji GeoTools はプラグインフォルダ内に固定プリセットを抱えず、QGIS プロジェクトファイルの横へ `プロジェクト名_KGT` フォルダを作成します。案件ごとに設定を持たせやすい構成です。

QGIS でプロジェクトを開く 未保存プロジェクトの場合は、ユーザーフォルダ側を基準に設定フォルダが作られます。
ツールバーから Koji GeoTools を起動 DPI と表示倍率を読み取り、QGIS 画面上で押しやすいサイズに調整されます。
必要なワークフローを選択 レイヤセット、区境界バッファ、ポリゴン内抽出の各ツールをランチャーから呼び出せます。
Download

QGIS の ZIP プラグインとしてインストールできます。

ダウンロードした ZIP は展開せず、QGIS の「プラグインを ZIP からインストール」から指定してください。QGIS 3.28 以降で利用できます。

同梱プリセットなし

プロジェクトごとの設定ファイルを使う設計のため、プラグイン ZIP には案件固有のプリセットやデータを同梱していません。

ベクター処理に特化

CSV からの点レイヤ作成、選択地物を基準にした区域処理、表示中レイヤからの抽出など、検討図作成の前処理を支援します。
