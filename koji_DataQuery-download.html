Release v0.1.0

koji DataQueryは、CSVとGeoPackageの前処理、CSV集計、CSV/GeoPackageのLEFT JOINとUNIONを扱うQGISプラグインです。QGIS版のPower Queryのような操作感を目指して開発されています。

配布ファイルはGitHub Releasesの `koji_DataQuery.zip` を想定しています。ZIPは展開せず、QGISのプラグイン管理画面から「ZIPからインストール」を選んで指定してください。

このページでは、Releaseページ、GitHub Actions、公開ソースコードへのリンクをまとめています。SHA256やVirusTotalの検査結果は、Releaseアセットを公開する際にGitHub側へ追記して確認材料として扱う想定です。

配布ファイルの検証情報

ローカルのmetadata.txtではバージョンは0.1.0、最小QGISは3.0、experimental=Trueです。SHA256とVirusTotal結果はこの作業時点のローカル情報からは確認できないため、未確認の値は掲載していません。

インストール手順

QGISプラグインとして使う場合は、通常のZIPプラグインと同じ手順でインストールします。

ZIPをダウンロードGitHub Release v0.1.0 から `koji_DataQuery.zip` をダウンロードします。ZIPは展開しません。
QGISのプラグイン管理を開くQGISで「プラグイン」メニューから「プラグインの管理とインストール」を開きます。
ZIPからインストール「ZIPからインストール」を選び、ダウンロードした `koji_DataQuery.zip` を指定します。

確認できること

  • GitHub Releasesで配布ファイルを確認できます
  • Release本文でSHA256を確認できます
  • GitHub Actionsでビルド履歴を確認できます
  • GitHubでソースコードを確認できます
